項目全体の学習地図

基準点完全バックアップ
変更分完全バックアップ以降の差分
復旧点どの時点まで戻したいか

復旧したい時点から必要なバックアップを選ぶ

場面週1回の完全バックアップと毎日の差分バックアップがある。
判断すること障害前の目的時点を再現するには何を組み合わせるか。
決定的な条件差分は直前の差分ではなく、最後の完全バックアップを基準にする。

必要な用語・概念

完全バックアップ：対象データ全体を保存し、復旧の土台になる。

差分バックアップ：最後の完全バックアップ以降の変更を、その取得時点までまとめて保存する。

復旧点：障害発生日ではなく、どの時点の状態へ戻したいかを先に決める。

項目全体の判断の地図

取得日だけでなく、各バックアップの基準点を見る。
差分方式では、基準となる完全バックアップと、復旧点に対応する最新の差分を組み合わせる。
