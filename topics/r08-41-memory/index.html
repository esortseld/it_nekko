項目全体の学習地図

保持するもの画面表示に必要な画像などのデータ
使う処理描画・画面表示
判断軸何のためのメモリか

画面表示に使うデータを保持する

場面PCが文字や画像を画面へ表示する。
判断すること表示データを置いておく専用メモリは何か。
決定的な条件PC全体のデータではなく、画面表示のためのデータを保持する。

必要な用語・概念

VRAM（Video RAM）：画面表示に必要なデータを保持するための専用メモリ。

RAM / ROMなども、名称だけでなく「何を保持し、どの処理で使うか」で役割を区別する。

項目全体の判断の地図

メモリは用途から見る。
保持するデータと、それを使う処理を確認し、画面表示専用ならVRAMと結び付ける。
