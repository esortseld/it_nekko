項目41 メモリ

トップ›テクノロジ系›項目41 メモリ

項目全体の学習地図

保持するもの画面表示に必要な画像などのデータ
使う処理描画・画面表示
判断軸何のためのメモリか

画面表示に使うデータを保持する

場面PCが文字や画像を画面へ表示する。
判断すること表示データを置いておく専用メモリは何か。
決定的な条件PC全体のデータではなく、画面表示のためのデータを保持する。

必要な用語・概念

VRAM（Video RAM）：画面表示に必要なデータを保持するための専用メモリ。

RAM / ROMなども、名称だけでなく「何を保持し、どの処理で使うか」で役割を区別する。

項目全体の判断の地図

メモリは用途から見る。
保持するデータと、それを使う処理を確認し、画面表示専用ならVRAMと結び付ける。

主記憶と補助記憶を区別する

場面
RAM、ROM、SSD、光ディスクなどを比較する。
判断すること
CPUが直接使う主記憶か、長期保存用の補助記憶か。
関係する知識
RAM、ROM、SSD、CD-ROM、DVD-RAM
学習要点
記憶装置は、揮発性・書換え可否・用途・記憶階層で整理する。
