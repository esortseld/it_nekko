項目37 アルゴリズムとプログラミング

この項目で理解すること

プログラム問題では、コードを一度に読もうとせず、変数の初期値、繰返しの範囲、条件が真になる時、更新後の値を順に追います。

変数の状態を一行ずつ追う

代入が行われるたびに変数の値は変わります。条件分岐では、現在の値で条件式を評価し、実行された側だけを反映します。途中の値を表にすると処理を見失いにくくなります。

繰返しの回数と境界を見る

forやwhileでは、開始値、終了条件、増分を確認します。「以下」と「未満」、配列の先頭・末尾などの境界が結果に影響します。二重ループでは内側が何回実行されるかを先に数えます。

配列と並べ替え

並べ替えでは、どの要素同士を比較し、どの条件で交換するかを見ます。選択ソートなら未整列部分から最小値などを探し、所定位置へ移します。処理後に「確定した範囲」が広がる点を追います。

数の性質を処理へ落とす

2進数から10進数への変換では各桁の重みを使い、素数判定では割り切れる約数が存在するかを調べます。図形描画でも、繰返し回数と1回当たりの回転角の関係を式へ置き換えます。

判断の軸

初期化 → 条件判定 → 処理 → 更新の順に追い、各反復後の状態を書き出します。アルゴリズム名より、値がどう変化するかを確認します。
