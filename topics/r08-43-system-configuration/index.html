項目43 システムの構成

この項目で理解すること

システム構成では、複数の装置やサーバをどう組み合わせるかによって、容量、性能、故障への強さ、共有方法が変わります。

RAIDは複数ディスクを組み合わせる

RAID 5では、データとパリティ情報を複数のディスクへ分散して保存します。1台分に相当する容量を冗長情報に使うため、同容量のディスクn台なら利用可能容量は概ね(n−1)台分です。

複製は別の場所にも同じデータを持つ

データベースやストレージを複数の装置へ複製すると、一方の障害時にも別系統を利用しやすくなります。単なるバックアップと、常時利用可能な複製は目的や同期方法が異なります。

NASはネットワーク越しにファイルを共有する

NASはネットワークへ接続し、複数の端末からファイル単位で利用できるストレージです。端末内部のローカルディスクとは異なり、共有利用を前提とします。

判断の軸

記憶容量をどう使うか、故障時に何を継続したいか、どこからアクセスするかを確認します。
