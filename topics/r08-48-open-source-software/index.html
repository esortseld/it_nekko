項目48 オープンソースソフトウェア

この項目で理解すること

OSSは、ソースコードを利用できる形で公開し、ライセンスで定められた条件の下で利用・改変・再配布できるソフトウェアです。「無料で使えること」と「ソースコードが公開されていること」は別です。

著作権はなくならない

OSSでも著作権者は存在し、著作権が自動的に放棄されるわけではありません。利用者は、権利者が示したOSSライセンスの条件に従って利用します。

改変・再配布はライセンス条件を見る

ソースコードを変更できることや再配布できることはOSSの重要な特徴ですが、どの条件で許されるかはライセンスによって異なります。改変部分のソースコード公開を求めるものなど、義務の内容を確認します。

無償か有償かはOSSの本質ではない

OSSは有償で提供されることもあります。一方、無料で利用できてもソースコードが公開されていないフリーウェアもあります。料金とソースコード公開を別の軸で考えます。

代表例はライセンスとともに見る

LinuxやFreeBSDなどは代表的なOSSです。製品名だけを覚えるより、利用・改変・再配布がどのようなライセンス条件に基づくかを確認することが重要です。

判断の軸

ソースコードが公開されているか、著作権が誰にあるか、利用・改変・再配布の条件は何かを分けて確認します。
